# Complete Evaluation Notebook

This folder contains the original final evaluation dashboard notebook:

- [`eval-complete-final.ipynb`](eval-complete-final.ipynb)

The notebook evaluates the adapted 100-epoch EagleVision checkpoint against the frozen DAV2 baseline, GT-depth warp, and identity baseline. It computes paired baseline-vs-adapted statistics, motion bucket metrics, depth-scale diagnostics, runtime/memory summaries, qualitative galleries, plots, and a final interpretation.
