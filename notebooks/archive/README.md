# Archived Notebooks

This folder preserves older, duplicate, or superseded notebooks for traceability.

## Policy

Archived notebooks are not the recommended entrypoint for new work. Prefer:

- `notebooks/experiments/` for active research
- `notebooks/ablations/` for ablation experiments
- `notebooks/kaggle/` for Kaggle workflows
- `notebooks/evaluation/` for evaluation workflows

If an archived notebook becomes useful again, move it into the appropriate active folder and update the folder README.
