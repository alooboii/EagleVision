# Documentation

This folder contains design notes, experiment notes, submission guidance, and paper-support files.

## Main Docs

- `architecture.md`: high-level system architecture.
- `phase1_scope.md`: what Phase 1 includes and excludes.
- `training_plan.md`: training workflow and planned progression.
- `experiments.md`: experiment tracking notes.
- `repository_guide.md`: contributor-facing repository guide.
- `kaggle_submission.md`: Kaggle execution and submission notes.
- `artifact_policy.md`: rules for data, outputs, checkpoints, and reports.
- `reproducibility.md`: how to reproduce tests, training, evaluation, and notebook reports.

## Paper Assets

- `eaglevision_paper_template.tex`: LaTeX paper template.
- `eaglevision_refs.bib`: bibliography file.

Keep documentation linked from the root `README.md` when it is important for new users.
