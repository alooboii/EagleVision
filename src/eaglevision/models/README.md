# Models

Model components live here.

## Contents

- `adapters.py`: lightweight residual depth adapter.
- `rt_depthnvs.py`: round-trip depth/NVS model composition.
- `depth/`: pretrained depth model wrapper.
- `fusion/`: depth fusion logic.
- `nvs/`: geometric novel-view-synthesis utilities.
- `refinement/`: refinement modules.

Keep architecture changes paired with config updates and experiment notes.
