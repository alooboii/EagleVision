# Utilities

Shared helper functions live here.

## Files

- `geometry.py`: projection, backprojection, and rigid transforms.
- `intrinsics.py`: camera intrinsics scaling.
- `io.py`: file I/O helpers.
- `masks.py`: mask utilities.
- `seed.py`: reproducibility helpers.
- `visualization.py`: visualization helpers.

Keep utilities small and covered by focused tests when possible.
